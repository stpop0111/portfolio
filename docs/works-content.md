# Works — 6案件 最終文言

ポートフォリオ Works セクション用のコンテンツ原稿。
構成は「課題 → 施策 → 結果（数値）」で統一。

実装側との対応:
- ArticleCard ← タイトル / サマリー / サムネ
- StoryBlock × 3 ← 課題 / 施策 / 結果
- MetricsGrid ← 数値ハイライト
- LockedArea ← 機密ロック対象（W-04 で使用）

---

## テンプレ（共通フォーマット）

```
### メタ
- 案件名:
- 担当領域:
- 期間:
- 業種・カテゴリ:
**∫**
### サマリー（1〜2文／カード表示用）
[ひと言で「何をしたか」「何が変わったか」]

### 課題（Problem）
[背景と問題。3〜5行。事実ベースで]

### 施策（Action）
[何を、なぜ、どう判断して動かしたか。考え方が伝わるように。5〜8行]

### 結果（Result）
[定量・定性の成果。誇張せず、文脈つきで]

### Metrics（MetricsGrid 表示用）
- 指標名: 数値（before → after / または ±%）
- 指標名: 数値

### 機密ロック
- 公開してOK: [...]
- 隠す: [...]
```
